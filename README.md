## 项目简介

每年高考出分后，家长和考生面对的最大问题不是「没有信息」，而是**信息太多、不会用**：几百页的招生计划、上千所院校的专业分数线、各省不同的选科要求和录取批次，靠人工翻根本理不清。

这套高考志愿查询平台把这些数据整理进系统，再用算法帮考生把「分数」变成「能上的学校和专业清单」：先按规则把不符合条件的选项筛掉，再对剩下的选项做适配度评分，最后用 TopN 排序输出推荐结果；考生有疑问还可以直接问 AI 机器人。

系统采用 B/S 架构，前后端分离：后端 Java + SpringBoot + MyBatis-Plus，前端 Vue + ElementUI，数据库 MySQL。

## 核心算法与实现说明

### 1. 规则式数据处理与决策

志愿推荐的第一步不是打分，而是**把不可能的选项先筛掉**：结合招生计划、选科要求、录取批次、历年分数线等硬性条件做规则过滤。这一层保证了进入后续评分的选项都是「有资格报」的，推荐结果才有效。

### 2. 适配度评分算法

通过规则过滤后，系统对剩余的「考生 × 院校专业」组合计算适配度：综合考生分数与位次、选科匹配程度、院校层次、地域偏好等多个因素量化打分，适配度越高代表这个志愿和考生的匹配程度越好。

### 3. TopN 排序算法

适配度算完后，按分数从高到低做 TopN 排序，输出推荐清单。模拟报志愿模块最终呈现给考生的就是这份排序结果——不用自己翻几百页招生计划，系统直接给出「值得报」的列表。

### 4. AI 问答

内置 AI 机器人支持对话式提问，覆盖高考政策、院校信息、专业选择等常见疑问；同时平台维护了常见问题库，作为 AI 之外的补充入口。

### 5. Echarts 图形化分析

管理端用 Echarts 呈现平台数据：各省院校数量分布、院校专业数量统计等，方便掌握数据规模与结构。
